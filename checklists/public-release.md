# Public Release Checklist

Use this before publishing workflow materials.

- [ ] No `auth.json`, tokens, cookies, credentials, or local account files.
- [ ] No raw private session transcripts.
- [ ] No SQLite runtime databases.
- [ ] No private machine names, private IPs, or personal host aliases unless intentionally documented as examples.
- [ ] No absolute local paths in reusable templates.
- [ ] Example tasks are synthetic or fully scrubbed.
- [ ] README explains what the repository is and is not.
- [ ] Templates are usable without a GUI or specific agent.
- [ ] License is present.

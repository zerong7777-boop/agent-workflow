# Evaluate A Small Workflow Change

## Objective

Decide whether a proposed workflow change improves restart quality for long-running agent work.

## Success Criteria

- The proposed change has a clear bottleneck.
- A bounded test is defined.
- The decision links to evidence.

## Constraints

- Do not use private session transcripts.
- Keep the example tool-agnostic.

## Unknowns

- Whether the change improves restart quality enough to justify adding it to the default template.

## Recommended Next Step

Write an experiment record that defines the bounded comparison.
